# Cadeira Livre: protótipo navegável

Protótipo mobile do MVP (alocação, reserva e gestão de cadeiras para cabeleireiros).
Arquivo único, sem build e sem dependências, exceto a fonte do Google Fonts (precisa de internet).

## Rodar localmente
python3 -m http.server 8000
Abra http://localhost:8000 (ou o IP da máquina, no celular, na mesma rede).

## Publicar no GitHub Pages
Settings > Pages > Deploy from a branch > main > / (root)

## Fluxos
- Profissional: Início, Verificação, Busca, Espaço, Confirmação, Reservas, Avaliação
- Anfitrião: Início, Cadeiras, Alocação, Painel, Financeiro
